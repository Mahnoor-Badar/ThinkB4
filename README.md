# ThinkB4

ThinkB4 is a child-focused cybersecurity awareness and simulation application.

## Tech Stack

- Python
- Streamlit
- Groq / LLM
- python-dotenv

## Project Structure

- `app.py` — Main application entry point
- `pages/` — Streamlit pages
- `ai/` — AI/LLM functionality
- `simulation/` — Cybersecurity scenarios and simulation logic
- `backend/` — Backend/data logic
- `components/` — Reusable UI components
- `assets/` — Images, icons, and styles
- `tests/` — Testing and QA
- `docs/` — Project documentation
